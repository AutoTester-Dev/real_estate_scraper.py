# Real Estate Property Scraper 🏠

A Python-based web scraping and data extraction tool designed to gather real estate listings, property prices, locations, and specifications for market research and analysis.

## 🛠️ Tech Stack
- **Python** (Core programming language)
- **BeautifulSoup** (HTML Parsing and data extraction)
- **Requests** (HTTP Requests handling)
- **Pandas & OpenPyXL** (Data structuring and clean Excel export)

## 📌 Features
- Extracts critical property details (Title, Price, Location, Bedrooms, Area).
- Cleans and formats raw property data into structured formats.
- Exports structured datasets directly into Excel (`.xlsx`) format for real estate analytics.
