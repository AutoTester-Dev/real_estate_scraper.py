# Real Estate Property Scraper 🏠

A Python-based web scraping and data extraction tool designed to gather real estate listings, property prices, locations, and specifications for market research and analysis.

## 🛠️ Tech Stack
- **Python**
- **BeautifulSoup** (HTML Parsing)
- **Requests** (HTTP Requests)
- **Pandas & OpenPyXL** (Data structuring and Excel export)

## 📌 Features
- Extracts critical property details (Title, Price, Location, Bedrooms, Area).
- Cleans and formats raw property data.
- Exports structured datasets into Excel (`.xlsx`) format for real estate analytics.
